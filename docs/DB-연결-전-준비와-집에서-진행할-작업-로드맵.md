# K-ONE SeoulEdu 진행 현황과 남은 작업

> 역할: 현재 프로젝트 구조와 Phase 진행 상태, 후속 작업 순서를 관리한다. 실행 방법은 [Flyway·OpenAPI 실습 매뉴얼](Flyway-OpenAPI-DB연동-실습-매뉴얼.md), 제품 요구사항은 [FAQ 검색 사이트 기획안](faq-search-site-plan.md), DB 구조는 [스키마 설계안](DB-스키마-설계-초안.md)을 따른다.

> 기준일: 2026-11-12. 화면·코드·마이그레이션 파일을 확인하고 기존 작업 기록과 대조했다. 실제 DB 연결은 수행하지 않았으므로 V7~V17 적용 여부는 미확인.

## 현재 프로젝트 구조

| 영역 | 구현 내용 | 파일·기술 |
|---|---|---|
| 프런트엔드 | 로그인, 검색 홈, FAQ 탐색, 관리자 회원 화면, 홈 대시보드, 통계 페이지 | `frontend/`, HTML·CSS·JavaScript |
| 백엔드 | 세션 인증, FAQ 검색·조회·열람 집계, 회원 관리, 통계 API | `backend/`, Java·Spring Boot |
| DB | FAQ·주제·키워드·사용자·집계·열람 이력 | MySQL 8.4, Docker Compose |
| DB 변경 | 스키마·초기 데이터·FAQ 콘텐츠 변경을 순서대로 실행 | Flyway V1~V17 |
| API 계약 | 명세 우선 OpenAPI 및 Swagger UI 확인 | `backend/src/main/resources/static/openapi.yaml` |
| 프로젝트 문서 | 제품 기준·FAQ 작성 기준·DB 스키마·실습 진행 기록 | `docs/` |

FAQ 화면은 레거시 `frontend/data/faq.json`이 아니라 백엔드 API에서 데이터를 조회한다. 이 JSON 파일은 저장소에 남아 있으나 현재 화면 데이터 원본은 아니다.

## Phase 진행 상태

| Phase | 내용 | 상태 |
|---|---|---|
| 0 | MySQL·Docker Desktop·Java 21·Spring Boot·Gradle 환경 | 완료 기록 있음 |
| 1 | API 계약을 OpenAPI 명세 우선으로 작성 | 완료 기록 있음 |
| 2 | Flyway 스키마·테이블·인덱스·관계 적용 | V1 적용 및 구조 확인 기록 있음 |
| 3 | 카테고리·초기 FAQ·참고 FAQ 데이터 입력 | V1~V6 적용 및 초기 집계 확인 기록 있음. 기존 UI에서 FAQ 369건 표시 확인 |
| 4 | FAQ API·세션 인증·OpenAPI 검증 | 구현·Swagger 주요 흐름 확인. 추가 권한 검증 남음 |
| 5 | 관리자 회원 API | 구현. 미인증·상담원 차단 확인 남음 |
| 6 | 프런트엔드 API 연동·대시보드·통계 | 구현. 기능별 브라우저 회귀 확인 중 |
| 7 | 통합 검증·운영 배포 준비 | 미완료 |

## 우선순위별 남은 작업

### 1. 새 개발 PC에서 로컬 환경 재현

- 회사 PC의 설치 정책에 따라 Docker Desktop 사용 가능 여부 확인.
- Java 21 설치와 저장소 체크아웃.
- Git에서 제외된 `.env`와 `backend/src/main/resources/application-local.properties`를 회사 개발용 비밀값으로 별도 생성.
- MySQL 컨테이너, Spring Boot, 프런트엔드를 실행해 접속 확인.

저장소에는 실제 비밀번호가 포함된 로컬 설정이 올라가지 않는다. 회사 PC에서 설정 파일을 별도로 준비해야 한다. 세부 실행 절차는 실습 매뉴얼과 README를 따른다.

### 2. 최신 Flyway 버전과 FAQ 데이터 확인

- DB의 `flyway_schema_history`에서 적용된 마지막 버전과 성공 여부 확인.
- V7은 양품화 FAQ의 내용 보강과 FAQ 12건 추가, V8은 기존 유지보수 FAQ·검색 키워드 보강, V9는 기존 Android FAQ 보강, V10은 ChromeOS FAQ 분류·제목·일부 본문 보완, V11은 기존 iOS FAQ 분류·본문 보완, V12는 Windows 및 ChromeOS Flex FAQ 분류·본문 보완, V13은 Whale FAQ 분류·본문 보완, V14는 DBS·MDM FAQ를 `시스템·관리` topic으로 분류·보완, V15는 기존 일반·운영 FAQ를 분류하고 종료·보안 관련 안내를 정돈하며, V16은 기존 FAQ 6건의 다항목 본문을 목록 구조로 재편하고 V17은 양품화 수량 차이·수리동의서·학교 예산 일괄 구매 정보를 기존 FAQ에 보강한다.
- V7~V17 적용 전후에 FAQ 행 수, 카테고리·주제별 데이터, 주요 항목을 대조.
- 마이그레이션 파일이 GitHub에 반영된 버전과 DB 상태를 일치시킴.

마이그레이션이 적용됐다고 확인하기 전에는 완료로 표시하지 않는다. 기존 이력을 고치거나 DB를 초기화하지 않는다.

### 3. Phase 6 브라우저 회귀 확인

- 로그인·로그아웃·세션 만료·직접 URL 접근.
- 검색, 대분류·주제 필터, 페이징, FAQ ID 직접 링크, 브라우저 뒤로 가기.
- FAQ 상세 열기·닫기에 따른 누적 조회수와 사용자별 최근 열람 이력.
- 홈의 최근 7일 조회 FAQ·최근 열람 FAQ·당일 조회 주제 갱신.
- 통계 페이지의 양품화·유지보수 대분류, 기간 변경, 차트·지표와 DB 집계 대조.
- 상담원/관리자 권한 차이, 오류·빈 결과, 모바일·키보드 동작.

최근 검색 결과는 입력 중 디바운스로 갱신하고, 최근 검색 기록은 Enter로 확정한 검색어만 저장한다. 한글 조합 중 Enter와 최근 검색 칩 선택은 기록에 추가하지 않는다.

### 4. FAQ 내용 검토

- 초기 승인 FAQ 38건과 V4 참고자료, V7~V17 반영 데이터를 구분해 검토.
- 내용 중복, 답변의 근거·조건·예외, 금액·일정·업체 정보의 적용 연도 확인.
- V7~V17 적용 후 주요 FAQ 표본을 문서 원본과 대조.

### 5. Phase 7 배포·운영 준비

- 프런트엔드·백엔드 호스팅과 운영 DB 선택.
- 도메인, HTTPS, CORS 허용 주소, 세션 쿠키 보안 속성 설정.
- 운영 비밀값 관리, 초기 관리자 생성, 사용자 계정 발급·비밀번호 변경 절차 정리.
- 백업·복구와 Flyway 운영 적용 계획 수립.
- 배포 환경에서 인증·권한·FAQ 보호·통계·로그아웃 흐름 검증.

## 현재 확인된 한계

- 이 문서 갱신 시 실제 DB에 연결하지 않아 V7~V17 적용 상태와 현 FAQ 최종 건수를 확인하지 못했다.
- 로그인 및 FAQ 목록 표시가 브라우저에서 확인됐지만, Phase 6의 모든 기능이 회귀 검증된 것은 아니다.
- 미인증 사용자·상담원 역할의 관리자 API 차단은 별도 확인이 필요하다.
- 운영 호스팅·도메인·운영 DB는 결정되지 않았다.
- README·이전 기획 문서의 일부는 더미 JSON 중심으로 작성돼 있어 현 상태와 차이가 있다. 해당 문서의 현행화가 진행 중이다.
