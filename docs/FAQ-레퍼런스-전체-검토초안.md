# FAQ 레퍼런스 전체 검토 초안

> 역할: 사용자가 제공한 레퍼런스 문의 331건을 프로젝트 FAQ 데이터 후보로 옮긴 검토 자료. 운영 DB 반영 전 제목·topic·내용을 확인하고 수정하는 작업본.

- 원시 문의 행 331건 수록. 빈 문의 행 18건 제외.
- 이 문서의 `R###`는 검토용 번호이며 DB ID가 아님.
- 첨부 자료의 답변은 `content` 초안으로, 미해결 메모는 `검토 메모`로 분리. 검토 메모는 운영 FAQ에 자동 포함하지 않음.
- 개인 이름은 담당 역할 표현으로 치환. 연도·기종·요율·연락 경로 등은 사용자가 확인할 수 있도록 가능한 범위에서 유지.
- 대분류는 기존 세 카테고리에 임시 배치. 과거 양품화는 양품화 카테고리에 두고 제목·내용의 연도를 보존하는 임시 규칙 적용.
